# LiveLight

直播间自动打光工具（Mac）。用摄像头看你的脸，自动调灯的亮度和色温，开着窗也能保持画面稳定。

- 支持的灯：爱图仕 amaran Verge
- 系统要求：macOS 15 及以上，Apple 芯片 Mac
- 不需要官方 App，配网和控制都在 LiveLight 里完成

## 下载

到 [Releases](../../releases/latest) 下载 `LiveLight-v0.1.zip`，解压后把 LiveLight 拖进「应用程序」。

第一次打开时 macOS 会提示无法验证开发者：打开「系统设置 › 隐私与安全性」，在下方点「仍要打开」。

## 使用

1. 灯开机后按住电源键，直到屏幕进度条走完（蓝牙重置）。
2. 打开 LiveLight，点右上角「+」扫描新灯，点「配网」。
3. 选好摄像头，点「自动」。
